# NISAR only: no Sentinel-1

Radar inputs come only from NISAR (L-band from NASA/ASF, S-band from ISRO). Sentinel-1 C-band is out entirely, as a fusion input and as a comparison. The frequency comparison the challenge brief invites is made between NISAR L-band and S-band. Sentinel-2 optical stays, but only for context and Proxy labels.

- Sentinel-1 as a side-by-side comparison on Showcase Sites: dropped.
